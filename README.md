# Power ATE · Windows 仪器控制软件

支持示波器、DC 源与电子负载的设置、控制和数据获取。

## 下载 0.2.0b12 测试版

打开[本版发布页](https://github.com/Saudade-Li/power-ate-releases/releases/tag/v0.2.0b12)，下载 **PowerATE-0.2.0b12-windows-x64-setup.exe**。同页 `.exe.sha256` 提供文件校验值。

安装包包含 Python、Qt 和程序依赖。连接仪器时使用兼容的 64 位 NI-VISA 或 TekVISA，安装向导提供运行库检测与原厂下载入口。

## 仪器与功能

| 仪器 | 功能 |
| --- | --- |
| Tektronix MDO3014 | 通道、水平、采集、触发、标签、截图及单通道／ALL 波形导出 |
| Tektronix DPO5034B | 通道、水平、采集、触发、带宽／DSP、标签、截图及单通道／ALL 波形导出 |
| Chroma 62024P-600-8 | 电压、限流、测量、保护、斜率、输出、定时、有限循环、电压扫描与渐变 |
| ITECH IT8816B | 四种稳态模式、在线调整、动态、电流序列、保护、起载、触发、感测、采样与操作记录 |

仪器参数按实际型号、档位、探头及功率条件核对。软件导出 CSV、JSON、PNG 和 SVG，可用 MATLAB 等工具分析。

## 本版更新

- 新增 IT8816B 独立页面，输入 ON 时可修改当前稳态设定，应用或回车提交并保持输入状态。
- DC 源和负载页面首次打开时创建，切换复用连接和草稿。
- 改善侧栏与页签动画，图标、文字和选中背景同步变化。
- 自动同步与操作记录保留编辑内容、滚动位置和选区。
- 全面整理帮助、版本说明和安装说明，按操作步骤、参数含义及结果查询组织内容。

按 F1 打开离线指南，使用“帮助 → 仪器手册”查看随包 PDF 和原厂文档来源。

## 安装与更新

首次使用：运行安装包，从开始菜单或桌面快捷方式启动，选择仪器页面并连接。

已有安装版：在“帮助 → 检查更新”选择“测试版（含稳定版）”，使用“下载并更新”；也可选择“仅下载”后“安装并重启”。默认来源为 `Saudade-Li/power-ate-releases`，清单缓存约 60 秒。

程序核对文件大小、SHA-256 和内置公钥对应的发布签名，等待仪器任务结束及连接释放后升级。b6 及更早版本可先手动安装当前包，随后使用程序内更新。个人设置、截图、波形和预设保存在用户目录。

测试结束后，通过软件正常断开与退出；通信失联时在仪器面板核对并关闭输出。安装目录的 third_party 提供第三方组件许可，仪器文档版权归对应权利人。

此仓库保存下载说明和更新元数据，GitHub 自动生成的 Source code 压缩包对应这两类文件。项目源码在独立私有仓库管理。
