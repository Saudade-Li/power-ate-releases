# Power ATE · Windows 安装包

本仓库仅提供 Power ATE 的安装包、版本说明与下载指引。

## 下载与安装

打开 [Releases](https://github.com/Saudade-Li/power-ate-releases/releases)，选择所需测试版本，下载 `PowerATE-版本号-windows-x64-setup.exe`。旁边的 `.exe.sha256` 文件用于核对下载内容。

安装包自带 Python、Qt 及运行依赖，无需另装 Python/Conda。USB 仪器仍需对应的 64 位 NI-VISA 或 TekVISA；程序帮助菜单中的安装 / VISA 指引提供官方入口。

b6 及更早版本需正常结束任务、关闭旧程序后手动安装 b7 一次；之后 b7 安装版支持对带受信任发布签名的后续版本自动更新。独立发布签名不同于 Windows Authenticode，首次手动安装仍可能显示未识别发布者。通过开始菜单或桌面快捷方式启动，升级与卸载保留用户设置、截图、波形和预设。

## 软件内检查与下载

“帮助 → 检查更新”使用以下配置，无需 GitHub 登录：

- GitHub 所有者：`Saudade-Li`
- 仓库：`power-ate-releases`
- 更新渠道：`测试版（含稳定版）`

稳定版渠道不列出测试版本。只有比当前程序更新的版本才会显示为可下载更新。下载会核对附件名称、大小及 GitHub 提供的 SHA-256。b7 的进度条显示百分比和校验阶段；安装版可选择“下载完成后自动安装并启动新版”，用内置公钥核验发布签名后自动升级。缺少可信签名的来源仍只允许手动安装。ATE.cmd 开发启动只下载，不覆盖源码。

## 0.2.0b7 的自动更新

[下载 0.2.0b7 测试版](https://github.com/Saudade-Li/power-ate-releases/releases/tag/v0.2.0b7)。一次确认后依次下载、校验发布签名、等待仪器任务结束并释放连接、退出、自动覆盖安装并启动新版。无需重复点击安装向导，不重装 VISA，不自动重启 Windows。安装失败时记录诊断日志并停止启动可能不完整的程序。

**旧 b6 及更早版本需手动安装本版一次，后续更新才能使用新流程。** 刚检查过旧清单时等待 60 秒缓存到期后再试。本版包含 b6 的 14 章分级帮助目录、章节跳转、返回目录与 Ctrl+F 查找。

## 0.2.0b5 及后续版本的安装与更新

安装向导可选择简体中文或 English。先检测可用的 64 位 VISA，已有时自动跳过；缺少时衔接 NI 官方下载、安装器选择、发布者签名验证和安装后复检。NI 登录、协议、管理员授权和必要重启由使用者完成，不随安装包再分发驱动。

默认版本查询使用本仓库的公开静态 `updates.json` 和短时缓存，不占用 GitHub REST API 匿名额度。旧安装版如遇 HTTP 403，请先从 Releases 手动下载安装 0.2.0b5 或更高版本一次。旧界面的渠道名称“测试版与稳定版”与新名称“测试版（含稳定版）”含义相同。

本仓库的自动生成 Source code 压缩包仅包含下载说明及更新元数据，不是私有项目源码。

## 使用范围

桌面工作台提供示波器连接、设置、截图和波形导出，支持深浅主题。实际可用功能受仪器型号、固件与附件限制，详情见程序内操作指南和每版发布说明。新版 DPO 全功能与干净 Windows 环境仍待完整实机验收，不能将模拟验证视为实机验收。

项目源码独立私有托管，本仓库不包含开发源码、个人仪器配置、运行结果或开发环境。第三方组件许可及来源随安装包提供，位于安装目录 `third_party`。
